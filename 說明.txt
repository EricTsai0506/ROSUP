掛機小幫手 使用說明（目前支援：RO Survivors 網頁版）
====================

一、怎麼執行（兩種方式擇一，都是視窗介面，不會出現命令視窗）
  A. 打包成應用程式（推薦）
     雙擊 build_exe.bat，完成後執行 dist\RoBot\RoBot.exe
     （整個 RoBot 資料夾要一起帶走，不能只拿 exe；可以對 RoBot.exe 按右鍵
       →「傳送到」→「桌面（建立捷徑）」）
  B. 直接執行
     安裝 Python（安裝時勾選 Add Python to PATH），然後雙擊 run.bat

  視窗介面：
    ▶ 開始 / ‖ 暫停 / ■ 停止
    「基本」「技能」分頁可直接修改常用設定，按開始時會自動儲存
    「進階設定檔…」開啟 bot_config.json 修改其他設定
    下方會即時顯示執行紀錄

一之二、操作方式（「基本」分頁選擇）
  背景（推薦）：程式開一個「遊戲專用的 Edge」（獨立設定檔、沒有網址列），
              直接把畫面和按鍵在你電腦內部傳給它，不經過真實的鍵盤滑鼠。
              → 這個 Edge 可以被其他視窗蓋住，你可以同時用其他瀏覽器或程式
              → 第一次請按「開啟遊戲用的 Edge」，在裡面登入遊戲
              → 視窗會固定成 1280×960（字的大小一致，辨識比較準）；
                被縮到最小或改變大小，10 秒內會自動還原
                （「基本」分頁可以取消勾選「固定遊戲視窗大小」）
              → 所有溝通都在本機（127.0.0.1），不會傳任何東西到遊戲伺服器，
                也不會在遊戲網頁裡執行任何程式碼
  前景：模擬真實鍵盤滑鼠，遊戲視窗必須在最前面（舊的方式）

  ※ 同時開其他程式時遊戲變卡：
     1. 按「Edge 效能設定」，把遊戲用 Edge 的「效率模式」關掉，
        並在「睡眠索引標籤」的例外加入 ro-survivors.com
     2. 本程式已自動降低自己的優先順序、限制文字辨識使用的 CPU 核心數，
        暫停或休息時也會停止截圖

二、熱鍵
  F8  暫停／繼續
  F9  結束
  滑鼠甩到螢幕左上角 = 緊急停止
  遊戲視窗不在最前面時，程式會自動暫停操作

三、第一次使用請先測試
  bot_config.json 裡 "dry_run": true 是測試模式：只辨識、不操作。
  執行一局後看 logs 資料夾：
    move_*.jpg       紅圈 = 金幣，紫圈 = 礦石，綠框 = 寶箱，黃十字 = 目標，箭頭 = 方向
    menu_*.jpg       綠框 = 程式要選的卡片
    bot_*.log        每一步的判斷紀錄
  確認沒問題後，把 "dry_run" 改成 false 才會真的操作。

四、bot_config.json 設定（用記事本開啟，存檔時保持 UTF-8）
  "window_title"      遊戲視窗標題的一部分，例如 "Chrome" 或遊戲名稱。
                      留空 "" = 用整個主螢幕（建議填，比較準也比較安全）
  "levelup"           升級選技能
     "hotkey"         開升級畫面的按鍵（畫面上「升級 1 B」的 B）
     "batch_min" / "batch_max"  累積幾次升級才按 B 一次選完（預設 3～4，每輪隨機）
     "max_level"                角色等級達到這個值之後不再按 B 升級（0 = 不限）
     "stop_before_end_sec"      打完最後 Boss 後會倒數 20 秒，這段時間不再升級
                                （計時器曾超過 5 分鐘、又變成這個秒數以下時判定，預設 25）
     "priority"       主力技能（目前：火箭術、冰箭術、雷擊術），越前面越優先
     "fourth_skill"   第四個技能。留空 = 沒有主力技能可選時隨便挑一個當第四
     "banish_fourth"  true = 之後第四技能再出現就按「放逐」
     "banish"         放逐清單（介面「技能」分頁勾選）。還沒有第四技能時，
                      清單裡的技能會先選一次當第四技能，下次出現才放逐；
                      「攻擊：屬性附加」不佔技能欄位，出現就直接放逐
     "throwaway_until_level" 到這個等級以前（預設 Lv3，也就是前兩次升級），
                      先隨便選一個非主力技能當「第四技能」，之後它出現就放逐
     "target_until_level" 到這個等級以前（含）優先選「增加目標」的卡，
                      之後優先選「傷害」或「冷卻」；同類型時選數值大的
                      預設 11 = 前 10 次升級（Lv2～Lv11）
     "target_words"   前期要找的效果字（預設：目標）
     "late_words"     後期要找的效果字（預設：傷害、冷卻）
     選卡順序：卡片等級（普通<優良<稀有<史詩<傳說）→ 效果類型 → 數值 → 技能順序
     "rarity_first"   false = 改成效果類型比卡片等級優先
     "max_reroll"     已有第四技能又沒主力可選時，最多按幾次「重抽全部」
     "think_sec"      選卡前的停頓秒數（模擬閱讀時間）
  "chest"             寶箱選能力（介面「寶箱」分頁可以排序）
     "priority"       寶箱的優先順序，越前面越優先（神、藥水、靈藥、祝福、料理共 50 種）
                      介面可以用滑鼠拖曳排序。「廣域藥水」「廣域祝福」各有範圍版和
                      近戰版，程式會看卡片效果有沒有「近戰」來分辨
     "prefer_rarity"  true = 沒有指定裝備時，選稀有度最高的
                      （傳說 > 史詩 > 稀有 > 優良 > 普通）
  "move"              自動走位
     "mode"           "keys" = 用方向鍵（WASD）移動
                      "mouse" = 按住滑鼠左鍵往目標方向移動
     "keys"           移動按鍵，方向鍵可改成 "up" "down" "left" "right"
     "coin_weight"    金幣的重要程度
     "ore_weight"     礦石的重要程度
     "chest_timeout"  追一個寶箱超過幾秒還沒撿到，就先放棄去撿別的
     "chest_threshold" 寶箱辨識門檻；誤認太多就調高（0.65），認不到就調低（0.55）
     "minimap"        true = 用右上角小地圖避開牆壁／水（預設開啟；怪怪的可以改成 false 關掉）
     "minimap_goals"  true = 畫面上沒東西撿時，往小地圖上的寶箱／磁鐵走
     "magnet_first"   true = 小地圖上附近有磁鐵就先去撿（畫面上有寶箱時還是先撿寶箱）
  "result"            結算畫面（你存活下來了／倒下）自動按「返回角色」
  "lobby"             「選擇大廳」畫面自動按「單人大廳」
                      以上兩項不要的話，把 "enabled" 改成 false
  "town"              回到城鎮後：走到「節慶主持人」旁，出現交談提示就按空白鍵
     "npc_keyword"    用 NPC 名字裡的哪幾個字來辨認（預設「主持人」）
     "npc_body_offset" NPC 身體在名字下方幾像素，走不到正確位置時可調整
     "talk_cooldown"  按完空白鍵後等幾秒才會再按
     之後出現活動視窗會按「開始遊戲」，出現「升級」視窗會按「前往野外」
     "start_button_pos" 讀不到「開始遊戲」字樣時，改按的位置（視窗寬高的比例）

  完整循環：戰鬥 → 結算按返回角色 → 單人大廳 → 找節慶主持人按空白鍵
            → 開始遊戲 → 前往野外 → 戰鬥 …
  "schedule"          休息排程（視窗介面「休息排程」分頁也能設定）
     "enabled"        true = 啟用
     "games_min" / "games_max"              每玩幾場休息一次（每輪隨機）
     "rest_min_minutes" / "rest_max_minutes" 休息幾分鐘（每次隨機）
     "stop_after_games"                     玩滿幾場自動停止（0 = 不限）
     ※ 一局結束回到城鎮後才會開始休息，不會打斷戰鬥
  "hud_ignore"        畫面上不要找金幣／寶箱的區域（介面面板），用比例表示

五、寶箱圖片
  templates 資料夾內的 chest*.png 是寶箱的樣子。
  如果你的遊戲視窗大小和截圖時不同，寶箱可能認不到：
  用 Win+Shift+S 截一個地上的寶箱（只截寶箱本身），
  存成 chest4.png 放進 templates 即可，可以放好幾張。

六、常見問題
  * 視窗一閃就關：現在不會了，錯誤會顯示在視窗並存到 logs\error.txt
  * exe 被防毒刪掉：改用 run.bat，或把 RoBot 資料夾加入防毒排除清單
  * 按鍵沒反應：先手動點一下遊戲畫面讓它取得焦點
  * 選錯卡片：把 logs 裡的 menu_*.jpg 傳給我看

【城鎮走路不卡的機制】
- 方向鍵只有 8 個方向，程式每一步都會先檢查「前方有沒有障礙」才走，噴水池的石頭邊也會當成障礙。
- 成功走到節慶主持人一次之後，會把路線記在 town_route.json，之後從同一個出生點就照這條路走（通常 4~5 秒到）。
- 若出生點不一樣、或照路線走還是卡住，會自動改回自己規劃路線；之後若找到更好的路線會自動換掉。
- 停下來讀字、剛起步的那一下不會被當成「卡住」；真的卡住時會往旁邊閃一下（或退後）再重新規劃，不會亂走。
- 視窗大小變了或走法怪怪的：在「基本」頁按「清除記住的路線」，下次會重新記。

【戰鬥中用小地圖避開牆壁】
- 程式會看右上角小地圖上自己的紅白箭頭，知道自己在地圖的哪裡。
- 一開始就知道不能走的：黑色（地圖外、懸崖）、藍色（水、藍綠色的牆）、比地板暗很多的東西（樹、石頭、坑洞）。
- 撞到一次的牆，會記住它的顏色，整張地圖同顏色的牆之後都會避開。
- 往前走之前先看小地圖前方有沒有牆，有就換一個走得通的方向；東西在牆的另一邊就先不追；
  沒東西撿時會往空曠、還沒去過的地方走。
- 每張地圖學到的地形存在 minimap 資料夾，下一場一進來就知道（線上更新會保留）。
  想重新學就把 minimap 資料夾刪掉。
- 小地圖被選單蓋住、或被縮小／放大時會自動暫停，不會亂判斷。請不要把小地圖關掉或放大（保持預設大小）。
- 每場結束會在紀錄寫「這局撞到東西 N 次」，可以比較看看。
- 畫面上沒東西撿時，會往小地圖上最近的寶箱（金色）或磁鐵（紅色 U 字）走，磁鐵優先；
  小地圖上附近有磁鐵時，就算畫面上有金幣也先去撿磁鐵（畫面上有寶箱時還是先撿寶箱）。
- 走不到（6 秒都沒更接近）或走到了卻撿不起來的圖示，會先跳過一陣子。

【斐揚洞穴頭目「月夜貓」：躲到鐘下（v1.6.12 重做）】
- 一場會有兩次：先出現「躲到鐘下！」，大約 12 秒後鐘響；接著出現「鐘開啟了！快躲到下面」，鐘換到別的地方，
  大約 23 秒後再響一次。沒躲到會被扣很多血（最難的難度大約 900），血不夠就直接倒下。
- 程式找的是鐘底下的圓盤：鐘蓋著、打開、只露出一小段在畫面邊緣都找得到。走到圓盤正中央後，
  會一直站到鐘消失為止（這段時間不躲紅圈，鐘響之前鐘的周圍本來就會有一圈紅色）。
- 畫面上看不到鐘（被上面的血條、下面的技能欄擋住，或在畫面外）：先上下移動找；
  看到往內縮的大紅圈，就照圓心走過去（圓心就是鐘）。
- 提示字沒讀到，頭目戰中看到很明顯的鐘也會去。
- 紀錄會寫「看到鐘了（在哪個方向、多遠）」「已經站到鐘底下（花了幾秒）」「躲鐘結束（HP 多少）」。
  過程每秒存一張圖在 logs\boss\bell_*.jpg；倒下的話最後 20 秒在 logs\boss\end_*.jpg，可以傳給我看。
- 視野要拉到最遠（預設會自動拉）。沒拉到最遠時鐘會比較大，程式會自己量一次大小再找。

【掛機統計】
- 視窗按鈕下面會顯示這次掛機的統計：掛了多久、打完幾場、每小時幾場、平均每場多久、每場撞牆幾次。
- 只算打完的場次；暫停和休息排程的時間不算。每場結束也會寫一行到紀錄。

【自動登入】（基本頁「啟用自動登入」）
- 5 分鐘沒動作被請離時跳出「暫離」→ 自動按「接受」。
- 登入首頁 → 按「開始遊戲！」。
- 角色選擇 → 點你在「基本」頁選的那一格（第 1~15 格，位置跟遊戲畫面一樣）→ 按「開始遊戲」。
- 選到空的格子會停下來並在紀錄裡提醒。
- 帳號需要重新輸入密碼時（登出／換電腦），請自己登入一次；之後就會記住。

【線上更新】（基本頁「線上更新」）
- 開程式時會自動檢查，也可以按「檢查更新」；有新版會跳視窗問你要不要更新。
- 按「更新」後會自動下載、換成新版並重開；設定檔、記住的路線、Edge 登入資料、紀錄都會保留。
- 只會連到 github.com 下載程式，不會連遊戲伺服器。
- 執行中無法更新，請先按「停止」。

【序號授權】
- 第一次開啟會跳出「輸入序號」視窗，上面有這台電腦的機器碼（可按「複製」）。
- 把機器碼和付款人姓名寄給賣家，收到序號後貼上、按「啟用」。
- 一組序號只能用在一台電腦；到期前 3 天「授權」欄會變黃色提醒。
- 請勿把電腦日期調到以前，程式會拒絕啟動。

【刷哪一關／難度】（基本頁）
- 關卡：節慶主持人（原本的關卡）或「遠征：關卡名稱」。遠征會跟遠征隊長對話、在左邊清單選關、按出發。
- 右邊的大標題讀不到時，點過那一關兩次就照點的那一關出發，不會一直卡在選關畫面。
- 選關失敗（沒有「出發」按鈕、清單裡找不到、點了好幾次右邊還是別關）會存一張圖到 logs（expedition_fail_*）、關掉視窗再試；
  連續失敗 3 次就先改刷節慶主持人 20 分鐘，之後再試遠征，不會整個停住。
  還沒解鎖或要先看劇情的關卡，請先手動處理一次。
- 難度：不調整＝照遊戲目前設定；最簡單＝滑桿全部拉到最左；最難＝全部拉到最右。


【頭目（MVP）閃避】
  頭目出現時（上方出現「MVP 名字」和紅色血條），程式會看地上的紅色／粉紅預警範圍：
  斜線雷射、直線、粉紅圓圈、扇形、湖水氾濫的波紋。
  - 角色站在預警範圍裡 → 往最近的安全地方走（小地圖說是牆的方向會避開）
  - 平常撿東西走路時，前方會踩進預警範圍 → 自動轉個方向
  - 斐揚洞穴「躲到鐘下」優先於閃避
  不想用可以在「一般」分頁取消勾選「頭目（MVP）出現時閃避地上的紅色預警範圍」。
  每次啟動前 3 場頭目戰會在 logs\boss 存截圖（boss_*），閃避時另存標了危險範圍的圖（dodge_*）。
  一局提早結束（多半是角色倒下）會存最後 20 秒的畫面（end_*），方便找出是被什麼打倒的。


【寶箱重抽／放逐／專注】
  「寶箱」分頁下方：
  - 排名在前 [10] 名之外的卡 → 按那張卡下面的「重抽」（0 = 不重抽）。三張都在前 10 名才直接選最前面的。
  - 排名在前 [0] 名之外的卡 → 按「放逐」（0 = 不放逐）。技能那邊的放逐（第四技能、攻擊：屬性附加）做完後才會放逐寶箱。
  - 排名在前 [3] 名的卡 → 先按那張卡的「專注」再選它（專注過的卡之後比較常出現；每種道具每局只專注一次，0 = 不用）。
  每個寶箱最多重抽 6 次；按了沒反應（次數用完、按鈕變灰）會自動停止，這局不再使用。專注也一樣。


【寶箱前期／後期排名】
  「寶箱」分頁上面選「前期排名」或「後期排名」，就可以分別排兩套順序（例如前期先拿傷害、後期改拿生存類）。
  - 遊戲時間到第 [7] 分鐘起改用後期排名（0 = 不分前後期，一直用前期排名）。
  - 後期排名沒有自己排過的話就跟前期一樣；按「後期排名重設成跟前期一樣」可以重來。
  - 道具欄滿了（道具 5/5）之後只會出現已經有的道具，所以後期排名主要決定「升級哪一個」。
    想在後期拿「新的」生存類道具，換成後期排名時道具欄要還有空位；或是前期就把它排進前 10 名先拿到。


【定時重開 Edge】（基本頁最下面，背景模式才有）
  掛很久瀏覽器會越來越慢、越吃記憶體。每 [6] 小時（0 = 不重開）會在一局打完、回城鎮時，
  把遊戲用的 Edge 關掉重開，接著自動登入、選角色、繼續掛。需要開「自動登入」；正在休息時會等休息完。
  只會關遊戲專用的那個 Edge，你自己平常用的 Edge 不受影響。


【每日報表】
  每打完一場會記一筆，存在 logs 資料夾：
  - report_日期.txt：當天摘要。通關／倒下幾場、倒在第幾分鐘、可能被什麼打倒、哪隻頭目扣最多血、最需要加強的地方。
  - report_日期.csv：每場一列（開始／結束時間、遊戲時間、結果、原因、最低 HP、角色等級、每隻頭目扣了幾 % 的血），可以用 Excel 開。
  視窗上按「今日報表」直接打開今天的摘要。
  一天裡換過關卡時，各關卡的場數和通關率會分開列。「跑得特別慢的場次」是遊戲本身變慢
  （螢幕關閉、電腦省電、被別的程式佔用…），那幾場實際花的時間比同一關平常多很多。
  「倒下」的判斷：最後讀到的 HP 是 0，或還沒打到最後的 MVP 就結束。原因：頭目在場（或剛打完）就算那隻頭目，
  不然看倒下前 30 秒在躲什麼（一大群怪物包圍、被怪物圍住、HP 掉很快）。


【頭目戰走位】
  遊戲時間 3、5、7、10、12、14 分會出頭目（14 分是 MVP）。
  - 頭目出現前 10 秒、頭目在場時、HP 低於 40% 時：不追遠處的寶箱／磁鐵，改成在空曠的地方一直繞圈移動，
    快撞牆、卡住、前面有紅色預警就換方向。
  - 站進紅色預警（十字斬、星形斬、斜線、圓圈、扇形）就往最近的安全處走。
  - 頭目打完會回到平常撿東西。
  設定檔 move 區：boss_times（頭目時間，秒）、boss_prep_sec（提前幾秒）、low_hp_kite（HP 比例，0 = 不用）、
  boss_kite（false = 關掉繞圈，只躲預警）。
